# Nikita Seiler — Portfolio

Personal portfolio showcasing selected projects in **data engineering, backend development, applied AI and solution architecture**.

**Website:** [nikita25-code.github.io](https://nikita25-code.github.io/)

## Overview

The site presents six project case studies, professional experience, technical capabilities and ways to get in touch. Its focus is on connecting business problems to practical, maintainable technology solutions.

## Built with

- HTML, CSS and vanilla JavaScript
- Responsive layouts and dark/light themes
- SVG animations and an interactive architecture illustration
- Filterable project case studies and accessible project details

The site is statically hosted using **GitHub Pages**. Project illustrations are visual demonstrations, not live connections to production systems.
